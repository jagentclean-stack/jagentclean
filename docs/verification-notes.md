# 前台導覽驗證紀錄

## 2026-08-14：CMS 動態導覽

- 桌機首頁已顯示由 `menus` 資料表提供的五個可見主選單：服務項目、清潔案例、清潔知識、關於我們、常見問題。
- 手機首頁維持 64–88px 等級的簡潔頁首，顯示品牌 Logo 與漢堡按鈕；桌機導覽不會擠入手機畫面。
- 行動版側邊抽屜採右側位移方式，沒有全螢幕半透明遮罩；關閉狀態以位移與 `pointer-events-none` 防止阻擋內容互動。
- 後續桌機截圖再次確認五個 CMS 主選單的排序與字色均正常；首頁 Hero 的主要諮詢行動按鈕與右側聯絡入口保持可見。

## CMS 選單頁存取驗證

- 未登入工作階段前往 `/cms/menus` 時，畫面正確顯示「您沒有權限存取此頁面」，未洩漏管理內容。
- `/admin/login` 可正常載入，並呈現兩個核准管理員帳號選項與密碼輸入欄位；實際登入 API 與受保護的 `cms.menus.list` 程序已由管理員會話驗證通過。
