# 潔特務人事薪資系統 V1.0｜已確認規格摘要

本文件將使用者於 2026 年 8 月提供的 V1.0 規格轉為本專案的可實作基準。所有薪資邏輯必須在伺服器端執行，並以資料庫中的薪資明細與快照保留當期計算依據。

## 核心不可變原則

歷史薪資不得因員工日薪、時薪、津貼或扣款規則後續調整而改變。每次薪資計算須將使用的費率、加班費、津貼、借支扣回與所有收入／扣款明細寫入薪資單及明細資料表。已核准薪資預設鎖定，僅具權限的帳號可解除鎖定，且必須留下理由與異動前後資料。

## 固定 V1.0 計算規則

| 規則 | V1.0 定義 |
|---|---|
| 餐費 | 每日實際工作滿 5 小時發放 $100；餐費為獨立津貼，不納入基本時薪、加班、遲到或早退計算基礎。 |
| 日薪制時薪 | 日薪 ÷ 8，採精確小數運算，最終於金額輸出階段依系統規則四捨五入。 |
| 半日薪 | 日薪 ÷ 2。 |
| 加班 | 日薪 ÷ 8 × 已核准加班時數；不可納入餐費。 |
| 遲到／早退 | 日薪 ÷ 8 × 對應時數。 |
| 主管津貼 | 僅在整日正常出勤時發放；半日、缺勤或請假不發放。 |
| 借支 | 由會計指定本期扣回金額；不得自動全額扣清，尚欠金額必須跨期結轉。 |

## 角色與資料可見性

| 角色 | 權限範圍 |
|---|---|
| ADMIN | 所有人事、薪資、確認、解除鎖定、報表與稽核紀錄。 |
| ACCOUNTING | 員工、排班、出勤、加班、借支、薪資、薪資條及報表；不可變更薪資核心公式。 |
| SUPERVISOR | 員工與排班檢視、出勤與加班審核；不可檢視全體薪資。 |
| EMPLOYEE | 僅限本人排班、出勤、加班、薪資與薪資條。 |

## 重要工作流

薪資狀態依序為 `draft → calculated → review → approved → paid`。`approved` 後預設鎖定，`paid` 後不可直接修改。系統提供上半月（1–15）、下半月（16–月底）及整月三種薪資週期，並保存發薪日、期間與當期資料快照。

九大畫面為 Dashboard、員工管理、排班管理、出勤管理、薪資計算、借支管理、獎金／津貼管理、薪資條管理與薪資支出報表。所有管理清單應提供搜尋、日期範圍、員工、狀態與薪資週期篩選及排序；會計高頻工作另提供批次排班、出勤、加班審核、薪資計算、薪資確認與薪資條建立。

## 驗收計算案例

日薪 $1,600 的正常 8 小時工作，餐費為 $100；4 小時工作餐費為 $0；2 小時加班費為 $400；遲到 1 小時扣款為 $200；半日薪為 $800，且不發主管津貼。這些案例將成為薪資計算引擎的自動化測試基線。
