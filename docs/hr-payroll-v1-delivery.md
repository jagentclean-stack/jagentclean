# 潔特務人事薪資系統 V1.0｜交付驗證

## 本版完成範圍

本版在既有潔特務清潔官網與 CMS 架構上新增人事薪資專用資料模型、受權限保護的 API 與九大後台畫面。員工、排班、出勤、加班、借支、獎金／津貼、薪資試算、薪資條、發薪與薪資支出報表均沿用既有登入及 RBAC 基礎。薪資資料會保留當期快照及逐項明細；已確認或已發薪的資料受工作流鎖定，操作會寫入稽核紀錄。

| 領域 | 已驗證內容 |
|---|---|
| 薪資規則 | 日薪 $1,600 的時薪、半日薪、餐費、加班、遲到、早退與主管津貼基線測試。 |
| 資料安全 | ADMIN、會計、主管與一般員工的角色隔離；一般員工僅可取得本人資料；銀行帳號只呈現遮罩末四碼。 |
| 工作流 | 草稿、試算、審核、確認、待發薪與已發薪的狀態轉換；確認後鎖定與稽核。 |
| 批次作業 | 週期自動建立、批次排班、出勤、加班審核、薪資試算及警示同步。 |
| 輸出 | 薪資支出 Excel、手機版薪資條 PNG，以及將瀏覽器渲染的薪資條影像封裝為可下載 PDF。 |
| 品質檢查 | 54 個測試檔、146 項測試通過；前端與伺服器生產編譯通過；Git diff 空白字元檢查通過。涵蓋薪資規則、週期邊界、角色隔離、鎖定工作流、六類異常警示、頁面篩選與匯出入口。 |

## 操作入口

人事薪資系統的入口使用 `/hr` 前綴，並由後台 Dashboard 顯示。管理員或會計可使用完整功能；主管可依權限查看與審核；一般員工僅能看到本人資料。薪資條頁可先選擇薪資週期與員工薪資條，再使用 **下載 PNG** 或 **下載 PDF**。已確認薪資條可在相同頁面建立待發薪、匯款、現金或其他方式的發薪紀錄。

## 發布前已知確認事項

驗證結果確認未登入狀態會顯示存取提示而不會永久轉圈。由於真實薪資資料屬敏感資訊，本輪自動化驗證未建立或插入任何示範員工、出勤或薪資資料；正式上線後應由具權限人員使用真實資料完成一次端對端操作覆核。
